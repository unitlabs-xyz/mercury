# @harbor/mobile

Expo + React Native, iOS only. Shares `@harbor/sdk` and `@harbor/types` with the web app.

**Not scaffolded yet, on purpose.** It starts in week two once the web app is carrying itself,
and it is first on the cut list. See [docs/08-roadmap.md](../../docs/08-roadmap.md) and open
question 3 in [docs/09-open-questions.md](../../docs/09-open-questions.md).

The web app in `apps/web` is the reference implementation. Build against it, not from scratch.
