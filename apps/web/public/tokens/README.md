# Token marks

Official xStocks token logos, published by Backed at
`https://xstocks-metadata.backed.fi/logos/tokens/<SYMBOL>.png` and used as the canonical icon for
these mints across Solana — it is the `icon` Jupiter's token API returns.

400×400 PNG with transparency. Each carries the issuer's own brand treatment, which is correct:
what a user holds is the tokenised wrapper, not the share directly.

Company names and marks are the trademarks of their respective owners.
